# Публикация на GitHub Pages

## Репозиторий

Целевой репозиторий — [knilseswork-pixel/workout_about](https://github.com/knilseswork-pixel/workout_about), ветка `main`. Разместите `index.html`, `logo.jpg` и папки `css/`, `js/`, `data/` в корне ветки. В настройках **Settings → Pages** выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**.

Публичная страница — [WORKOUT Sport Center](https://knilseswork-pixel.github.io/workout_about/).

## Загрузка материалов

При каждом открытии страницы сайт запрашивает `data/content.json`, `data/sections.json` и `data/site-config.json` из ветки `main` на GitHub. Публичная часть показывает опубликованные данные. Когда GitHub недоступен или файл повреждён, на странице появляется сообщение об ошибке. Черновики доступны из админки в том браузере, где их сохранили.

## Редактирование и публикация

1. Откройте **«Админ»** и сохраните черновик материала, раздела или настроек конструктора.
2. Во вкладке **«Публикация»** введите токен GitHub с правом записи в **Contents** репозитория и нажмите **«Опубликовать черновики в GitHub»**.
3. После подтверждения коммита админка покажет ссылку на него и загрузит опубликованную версию. При следующем открытии страницы посетители получат данные из ветки `main`.

JSON и новые вложения из `attachments/` публикуются одним коммитом. Пределы для загружаемых файлов составляют 10 МБ для фото и 25 МБ для видео. Встроенные ссылки на внешние фото и видео продолжают работать.

GitHub Pages доставляет саму страницу и её скрипты. После обновления файлов сайта дождитесь завершения развёртывания в разделе **Actions**.
